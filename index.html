Insurance Claims-Exception Agent

Agentic AI and workflow automation

Enthiram.ai, 2025–now

Built an autonomous agent that handles commercial insurance claim exceptions, the flagged cases that used to wait in a manual review queue. Running as a durable workflow on Temporal.io, it works through each case end to end, turning a two-week backlog into same-day decisions.

14 days → 3.5 hours per claim exception, processed autonomously

Built with Python, LangGraph, LangChain, Temporal.io, MCP servers, Claude and OpenAI APIs, PostgreSQL, FastAPI, DeepEval, LangSmith, Docker, Kubernetes, AWS

Open-Weight Gateway & SLM Semantic Router

LLM infrastructure and cost engineering

Enthiram.ai, 2025–now

Designed and built an LLM gateway that sits in front of all of the organisation's AI traffic. A semantic router classifies each request, serves routine queries from self-hosted small language models (Phi-4, Llama 3.2, DeepSeek-Distill) on vLLM, and escalates only complex reasoning to Claude, giving teams one endpoint with far lower running costs.

52% lower LLM API spend, $380K saved a year, with my team

Built with Python, FastAPI, vLLM, LiteLLM proxy, Phi-4, Llama 3.2, DeepSeek-Distill, Claude API, Sentence-transformer embeddings, Redis caching, Docker, Docker Compose, Kubernetes, NVIDIA GPUs and CUDA, Prometheus and Grafana, GitHub Actions

SOC 2 Type II Market Research & Content Writing Agents

Built two agents that work as a team inside SOC 2 Type II controls. The research agent scans the web and company sources, profiles competitors and writes a cited market brief. SOC 2 Type II controls on every step: full audit trail, PII redaction and role-based access

Research

Published work on keeping long-running AI agents inside the rules they are given.

Charter Coherence Protocol: Eliminating Context Rot in Long-Running Autonomous Multi-Agent Enterprise Systems

Published research paper, lead author

International Journal of Advanced Research in Science and Technology, Vol. 15, Issue 09, 2026

When AI agents run for days, the policy rules that govern them fade. The paper names this decay context rot and presents the Charter Coherence Protocol (CCP), which keeps those rules in force and checks every tool call against them, without changing the model or the orchestration framework.

60–79% → 0 rule violations executed at tools, in every scenario tested
